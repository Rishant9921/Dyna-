# Dynamic Island for Windows

A dependency-free .NET 9 WPF desktop overlay that starts visibly at the top-centre of the active display.

## Included

- Top-edge, top-centre reveal and a 5-second idle collapse.
- Smooth spring-style fade when expanding.
- Multi-monitor-aware placement based on the display under the pointer.
- In-session clipboard history and an eight-day calendar view.
- Hardware battery and Wi-Fi status.
- Media transport and volume controls using Windows' global media keys.
- In-app notification status feed.
- Settings for topmost mode and launch-at-sign-in (gracefully disabled when Registry access is unavailable).
- A normal Windows `.exe` generated by the project build.

## Run

```powershell
dotnet run --project .\DynamicIsland\DynamicIsland.csproj
```

## Build a release executable

```powershell
dotnet restore .\DynamicIsland\DynamicIsland.csproj --ignore-failed-sources
dotnet build .\DynamicIsland\DynamicIsland.csproj -c Release --no-restore
```

The framework-dependent executable is produced under `bin\Release\net9.0-windows\DynamicIsland.exe`. It requires the .NET 9 Windows Desktop Runtime.
